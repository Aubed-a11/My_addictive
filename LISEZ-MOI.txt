CE QUI EST INCLUS DANS CETTE LIVRAISON
-----------------------------------------
- Navigation unifiee (un seul menu, une seule couleur d'accent jaune) partout
- Billetterie et Livestream separes en deux ecrans distincts
- Date/heure + description sur chaque evenement
- Selection de taille obligatoire pour les vetements (panier + admin)
- Adresse de livraison + frais de livraison (1000 FCFA) affiches et
  requis avant validation du panier
- Ecrans vides (portefeuille, billets, favoris) avec bouton d'action
- Libelles bruts (EN_LICE, HIGH_TECH, afro#...) mis en forme proprement
- Compteurs a zero masques

COMMANDES DE REDEPLOIEMENT
-----------------------------

1) FRONTEND (mobile-app) -- aucune action serveur requise, juste GitHub :
   - Remplace entierement ton dossier mobile-app par celui de ce zip
   - Dans le dossier racine "myaddictive" :
       git add -A
       git commit -m "Audit UX : navigation unifiee, infos manquantes, tailles, livraison"
       git push
   - Vercel redeploiera automatiquement.

2) BACKEND (live-service + boutique-service) + ADMIN DASHBOARD :
   - Copie les 12 fichiers listes ci-dessus aux emplacements indiques
   - Dans le dossier racine "myaddictive" :
       git add -A
       git commit -m "Audit UX : description evenement, tailles, adresse/frais livraison"
       git push
   - Connecte-toi au VPS puis :
       ssh root@76.13.37.17
       cd /opt/myaddictive
       git pull
       mvn -DskipTests clean package -pl live-service -pl boutique-service
       docker compose --env-file .env.production up -d --build live-service boutique-service admin-dashboard

   (Patiente quelques minutes apres le redemarrage des services, le
   serveur est lent a redemarrer completement -- voir historique.)
