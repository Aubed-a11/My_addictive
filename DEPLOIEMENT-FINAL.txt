===========================================================================
Sur ton PC (frontend) : voir 1) plus bas.
Sur le VPS (backend), apres  scp my-addictive-complet.zip root@76.13.37.17:/root/  :

DEPLOIEMENT DE CETTE VERSION (09/10/2026) - My Addictive
========================================================

Ce zip contient le projet complet SAUF les fichiers propres au serveur, qu'il
ne faut jamais ecraser : docker-compose.yml, deploiement/, nginx/, .env*,
media-service/uploads, .git, target, node_modules.

Contenu : paiements corriges (faille du webhook fermee, verification serveur
KKiaPay, fan club en vrai paiement), connexion Google (Client ID deja integre),
email reel, lecteur video, filtre des titres, telechargement hors ligne, splash 2 s.

=== 1) APPLICATION (Vercel) =================================================
Remplacer le dossier mobile-app de ton PC par celui du zip, puis, depuis la
RACINE du projet (pas depuis mobile-app) :
  git add -A
  git commit -m "Paiements securises, connexion Google, lecteur video, correctifs"
  git push
Attendre le deploiement Vercel, puis vider le cache du navigateur
(F12 > Application > Clear site data) et recharger deux fois.
Le Client ID Google est deja dans le code : aucune variable a ajouter sur Vercel.

=== 2) SERVEUR (VPS, en root) - une commande a la fois ======================
  scp my-addictive-complet.zip root@76.13.37.17:/root/

Sur le VPS :
  cd /root && rm -rf my-addictive && unzip -oq my-addictive-complet.zip -x "my-addictive/mobile-app/*"
  cp -r my-addictive/. /opt/myaddictive/
  cd /opt/myaddictive

Cles (email Gmail, KKiaPay) : elles sont deja dans le fichier ajouter-cles-serveur.sh
de ce zip, qui est dans .gitignore (donc jamais envoye sur GitHub avec git add -A).
  bash ajouter-cles-serveur.sh
(il demande la cle PRIVEE KKiaPay tpr_..., a laisser vide si tu ne l'as pas)
Puis, par securite : rm ajouter-cles-serveur.sh
Ne JAMAIS retirer ce fichier du .gitignore : le depot GitHub est public.

Lignes a ajouter dans docker-compose.yml (SEULEMENT si absentes) :
 - bloc compte-service, sous ADMIN_MOT_DE_PASSE :
     MAIL_USERNAME: ${MAIL_USERNAME:-}
     MAIL_PASSWORD: ${MAIL_PASSWORD:-}
 - bloc paiement-service, sous KKIAPAY_SECRET_KEY (une seule commande) :
     sed -i '/KKIAPAY_SECRET_KEY: /a\      KKIAPAY_WEBHOOK_SECRET: ${KKIAPAY_WEBHOOK_SECRET:-}\n      KKIAPAY_PUBLIC_KEY: ${KKIAPAY_PUBLIC_KEY:-}\n      KKIAPAY_PRIVATE_KEY: ${KKIAPAY_PRIVATE_KEY:-}\n      KKIAPAY_SANDBOX: ${KKIAPAY_SANDBOX:-true}\n      PAIEMENT_SIMULATION: ${PAIEMENT_SIMULATION:-false}' docker-compose.yml
   Verifier : grep -n "KKIAPAY\|MAIL_" docker-compose.yml

Compiler (4 services modifies) :
  mvn -DskipTests clean package -pl compte-service,paiement-service,gateway-service,live-service

Reconstruire, UN service apres l'autre (le VPS n'a qu'1 CPU) :
  docker compose --env-file .env.production build config-service
  docker compose --env-file .env.production build compte-service
  docker compose --env-file .env.production build paiement-service
  docker compose --env-file .env.production build gateway-service
  docker compose --env-file .env.production build live-service
  docker compose --env-file .env.production up -d
Attendre ~5 minutes (inscription dans Eureka), puis :
  docker compose --env-file .env.production restart proxy

=== v11 : BASE UNIQUE SQLITE, SANS LECTEUR MEDIA NI TELECHARGEMENT ===
1. Une seule base SQLite (fichier /app/shared-db/myaddictive.db dans le volume Docker data_db),
   partagee par les 7 services avec base. Chaque service prefixe ses tables :
   compte_*, media_*, musique_*, live_*, votes_*, boutique_*, paiement_*.
   Mode WAL + busy_timeout 30 s + transaction_mode=IMMEDIATE pour les ecritures concurrentes.
   Fichiers : docker-compose.override.yml (volume), config-repo/*.yml (datasource), PrefixedNamingStrategy.java
   dans chaque service, pom.xml (sqlite-jdbc + hibernate-community-dialects).
2. Deploiement : bash redeployer-tout.sh (cree la base et les tables), puis UNE FOIS
   bash migrer-vers-sqlite.sh pour reprendre les anciennes donnees H2 (sauvegardes dans /opt/sauvegardes).
3. Retour en arriere : les anciens volumes H2 ne sont pas supprimes ; redeployer le zip v10 les reutilise.
4. Application : lecteur video integre supprime (boutons "Regarder le direct / replay / clip" qui ouvrent le lien),
   telechargement de titres supprime (ecran Hors ligne, boutons, compteur, Top Telechargement gratuit).
   L'ecoute en ligne des titres reste disponible.
5. (v11b) Lecteur de musique supprime aussi : plus d'ecran d'ecoute, les titres s'affichent en fiche (genre, prix, achat, lien vers le clip YouTube s'il existe).
